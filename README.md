# 🎮 슬라임 머지 디펜스 (Slime Merge Defense)

같은 무기를 드래그해서 합치고, 몰려오는 슬라임 무리를 막아내는 **머지 디펜스** 캐주얼 게임입니다.
별도의 설치나 빌드 없이 브라우저에서 바로 실행되는 단일 HTML 파일(`index.html`)로 만들어졌습니다.

## 🕹️ 플레이 방법

1. `index.html` 파일을 브라우저로 열면 바로 시작됩니다. (모바일 터치 / PC 마우스 모두 지원)
2. **무기 구매** 버튼으로 아래 격자판에 무기를 소환하세요.
3. **같은 등급의 무기를 드래그해서 겹치면** 한 단계 높은 무기로 합성됩니다. (⛏️ → 🗡️ → 🏹 → … 총 10등급)
4. 무기들은 자동으로 가장 가까이 다가온 슬라임을 공격합니다.
5. 슬라임이 빨간 방어선에 닿으면 ❤️ 생명이 줄어들고, 0이 되면 게임 오버!
6. **5의 배수 웨이브**마다 강력한 👑 보스가 등장합니다.
7. 최고 도달 웨이브 기록은 브라우저에 자동 저장됩니다.

## 🎯 전략 요소

- **업그레이드 상점**: ⚔️공격력 / ⏩공격속도 / 💰골드 획득량 강화
- **액티브 스킬**: ☄️ 메테오(광역 폭격), ❄️ 프리즈(적 전체 감속) — 쿨다운 관리가 핵심!
- **적 종류**: 일반 / 🔴돌진형(빠름) / 🔵탱커(단단함) / 🟢분열형(죽으면 2마리) / 👑보스
- **뽑기 운**: 첫 웨이브부터 낮은 확률로 최고 등급 무기 등장
- **⏩ 2배속** 지원

## ✨ 특징

- 순수 HTML5 Canvas + Vanilla JS — 의존성 0개, 파일 1개
- 드래그 & 드롭 합성 (이동/교환/합성 자동 판별, 합성 가능 슬롯 하이라이트)
- 웨이브가 진행될수록 강해지는 적 + 보스 웨이브
- WebAudio 기반 효과음 (🔊 버튼으로 켜고 끄기)
- 파티클, 화면 흔들림, 데미지 이펙트 등 타격감 연출
- 모바일 세로 화면에 최적화된 반응형 스케일링
