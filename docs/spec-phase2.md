# Phase 2 구현 명세 — 콘텐츠 확장

대상 파일: `/home/user/casualgame/index.html`
원칙: 기존 코드 스타일 유지, 외부 라이브러리 금지, Phase 1 기능(메타/카드/도감) 무결성 유지.

## 2-1. 신규 적 4종

`spawnEnemy()`의 타입 룰렛 확장 (기존: fast/tank/split/boss). 서로 배타적.

1. 💚 **힐러** (`healer`, 웨이브 12+, 확률 10%)
   - 체력 0.8배, 속도 0.8배. 꽃 색 `#4fd9a8`.
   - 2초마다 반경 120 내 다른 슬라임 체력을 `자기 maxHp의 8%`만큼 회복 (최대 maxHp까지).
   - 회복 시 대상에게 초록 + 파티클, 힐러 주변 링 이펙트.
2. 🛡️ **방패병** (`shield`, 웨이브 14+, 확률 10%)
   - 체력 1.2배. 꽃 색 `#c0c8d8`. `shieldHits: 5` — 첫 5회 타격을 무효화(데미지 0, "막음!" 표시).
   - 타격 무효 시 금속 파티클. 남은 방패 수를 몸 위에 작은 🛡️x N 로 표시.
   - 화상 지속 피해는 방패를 소모하지 않고 그대로 적용 (관통 카운터).
3. 👻 **유령** (`ghost`, 웨이브 16+, 확률 8%)
   - 체력 0.7배, 속도 1.1배. 꽃 색 `#b8a8e8`.
   - 2초 주기로 실체(2초) ↔ 무적(1.2초) 반복. 무적 중 반투명(알파 0.35) + 모든 데미지 무효.
   - 무적 중에도 이동은 계속. 방어선 피해는 정상.
4. 🎈 **풍선** (`balloon`, 웨이브 10+, 확률 10%)
   - 체력 1 (아무 공격이든 1방), 속도 1.9배, 크기 0.7배. 꽃 색 `#ffd0e8`.
   - 한 번에 3~5마리 묶음 스폰(스폰 큐 1 소모로 무리 생성).
   - 처치 골드 0.4배.

우선순위: boss > fast > tank > split > healer > shield > ghost > balloon 순으로 룰렛 구간 배정 (겹치지 않게 누적 확률).

## 2-2. 보스 패턴 3종

보스 스폰 시 `bossType = (wave / 5) % 3` 로 로테이션:

1. **소환사** (`summoner`): 3초마다 미니 슬라임 2마리 소환 (체력 = 보스 maxHp의 3%, 일반 취급). 소환 시 보라 파티클.
2. **돌진왕** (`charger`): 체력이 75/50/25% 이하로 떨어질 때마다 1.2초간 속도 4배 질주 + 화면 흔들림.
3. **빙결왕** (`chiller`): 보스가 있는 동안 보스와 같은 레인(±1칸) 무기 공속 30% 감소. 해당 무기 칸에 ❄ 오버레이 표시.

보스 이름 표시: 스폰 시 "👑 [패턴명]" 플로트 텍스트.

## 2-3. 스테이지 테마

10웨이브 단위로 배경 테마 전환 (`themeIndex = floor((wave-1)/10) % 5`):

| # | 테마 | 잔디(밝/어둠) | 기믹 |
|---|---|---|---|
| 0 | 🌱 초원 | 기존 색 유지 | 없음 |
| 1 | 🏜️ 사막 | `#d9c77a` / `#c9b25e` | 적 이동속도 +10% |
| 2 | 🌋 화산 | `#8a5a4a` / `#7a4a3a` | 적 체력 +15% |
| 3 | ❄️ 설원 | `#c8dce8` / `#b0c8da` | 무기 공속 -10% |
| 4 | 🌌 우주 | `#3a3a5e` / `#2e2e4e` | 적 속도 +10% & 체력 +10% |

- `drawField()`의 색상을 테마 팔레트에서 취득.
- 테마 진입 웨이브 시작 시 "테마 돌입!" 안내 플로트 + 기믹 설명 1줄.
- 기믹은 spawnEnemy(체력/속도)와 유닛 cd 계산에 곱연산.

## 2-4. 이벤트 웨이브

웨이브 시작 시 10% 확률 (보스 웨이브 제외), 서로 배타적:

1. 💰 **골드 러시**: 이 웨이브 처치 골드 3배. 안내 + 금색 화면 테두리.
2. 🌊 **러시아워**: 적 수 2배, 클리어 보너스 3배. 안내 + 빨간 테두리.
3. 🎁 **보물 슬라임**: 웨이브 중 1마리, 좌우로 빠르게 도망다니는 슬라임(방어선으로 안 내려옴, 8초 후 도주). 잡으면 최고 등급 -2 무기 드랍(최소 1).

이벤트 상태는 웨이브 종료 시 해제.

## 검증 기준 (리뷰어 체크리스트)

1. 신규 적 4종: 스폰 확률 구간이 겹치지 않는가, 각 고유 능력이 실제로 동작하는 코드인가 (힐러의 회복 대상 탐색, 방패 소모, 유령 무적 토글, 풍선 묶음 스폰)
2. damageEnemy가 방패/유령 무적을 올바르게 처리하는가 (킬/골드 로직 무결성)
3. 보스 패턴 3종이 로테이션되고, 빙결왕 오라가 무기 공속에 실제 반영/해제되는가
4. 테마 전환이 drawField와 스탯 계산 양쪽에 반영되는가
5. 이벤트 웨이브 상태가 종료 시 확실히 해제되는가 / 보물 슬라임이 방어선 피해를 주지 않는가
6. Phase 1 기능(카드/메타/도감) 및 기존 기능 파손 없음, JS 오류 0건
