# Phase 3 구현 명세 — 완성도 & 감성 (Juice)

대상 파일: `/home/user/casualgame/index.html`
원칙: 기존 코드 스타일 유지, 외부 라이브러리 금지, Phase 1·2 기능 무결성 유지.

## 3-1. 사운드 확장

1. **절차 생성 BGM** (WebAudio)
   - 간단한 4마디 루프: 베이스(사각파) + 아르페지오(삼각파). `setInterval` 금지 — 오디오 클록 기반 스케줄링(lookahead 패턴).
   - 웨이브가 오를수록 BPM 소폭 상승 (90 → 최대 140). 보스 웨이브는 단조 스케일로 전환.
   - 게임 중에만 재생, 타이틀/일시정지 시 정지.
2. **사운드 설정 분리**: 🔊 버튼 → 3단 토글 (전체 ON / 효과음만 / 음소거). 아이콘 🔊/🔉/🔇.
3. 보스 등장 시 경고음, 20등급 합성 시 팡파레.

## 3-2. 연출 강화

1. **히트스톱**: 보스 처치 시 0.15초간 게임 로직 정지(연출용 timeFreeze 변수, update 초반에서 감산 후 return). 파티클/플로트는 계속.
2. **콤보 카운터**: 처치 간격 2.5초 이내면 콤보 +1, 아니면 리셋. 5콤보부터 화면 상단에 "🔥 x N COMBO" 표시(커질수록 크기·색 변화). 10콤보마다 보너스 골드 `콤보 x 웨이브` 지급.
3. **20등급 첫 합성 컷인**: 화면 전체 플래시 + "🌈 신의 심판 강림!!" 대형 텍스트 + 무지개 파티클 폭발 + 1초 히트스톱.

## 3-3. UX 개선

1. **무기 툴팁**: 무기를 0.4초 이상 길게 누르면(드래그 이동 없이) 툴팁 표시: 이름, 등급, DPS(공식: dmg × rate × 배수), 공격 방식 한 줄 설명. 손 떼면 닫힘. TIER_DESC 배열 20개 필요.
2. **일시정지**: 상단바에 ⏸ 버튼 → `state="pause"` 오버레이: 이어하기 / 다시 시작 / 타이틀로. 일시정지 중 전투 정지.
3. **자동 저장 & 이어하기**:
   - 웨이브 클리어 시마다 런 상태 스냅샷을 `localStorage 'smd_save'`에 저장: `{wave, gold, lives, kills, grid(tier만), upg, runBuffs, peakTier, buyCount}`.
   - 게임 오버/포기 시 세이브 삭제.
   - 타이틀에서 세이브 존재 시 "▶ 이어하기 (웨이브 N)" 버튼 표시 → 복원 후 해당 웨이브 시작 대기 상태로 재개.
   - 파싱 실패 시 무시하고 새 게임 (안전 폴백).

## 검증 기준 (리뷰어 체크리스트)

1. BGM 스케줄러가 오디오 클록 기반인가 (setInterval/setTimeout 루프로 음 찍기 금지), 상태 전환(타이틀↔플레이↔일시정지)에서 확실히 시작/정지되는가
2. 히트스톱 중 입력/렌더는 살아있고 전투 로직만 멈추는가
3. 콤보 타이머·보너스 지급 로직이 킬 경로(killEnemy) 전체에 걸리는가
4. 툴팁이 드래그와 충돌하지 않는가 (길게 누르기 vs 드래그 판별)
5. 세이브/복원 라운드트립: grid 복원 시 cd/pop 등 런타임 필드 초기화, 저장 삭제 타이밍, 구버전/깨진 JSON 폴백
6. 일시정지 중 스킬 쿨다운/자동생성/웨이브 타이머 정지
7. Phase 1·2 및 기존 기능 파손 없음, JS 오류 0건
