# Phase 1 구현 명세 — 게임 루프 완성

대상 파일: `/home/user/casualgame/index.html` (단일 파일 게임, 순수 Canvas/JS)
원칙: 기존 코드 스타일(전역 함수, 한국어 주석) 유지. 외부 라이브러리 금지. 모든 UI는 캔버스에 그린다.

## 1-1. 영구 성장 (별조각 메타 프로그레션) ⭐

### 데이터
- `localStorage 'smd_shards'`: 보유 별조각 (정수)
- `localStorage 'smd_meta'`: JSON `{ gold: 0, tier: 0, lives: 0, cdr: 0, luck: 0 }` (각 항목 레벨)

### 획득
- 게임 오버 시: `획득 = floor(wave * 2 + kills / 20)` 별조각. 총량에 합산 저장.
- 게임 오버 화면에 "+N ⭐" 표시.

### 메타 상점 (타이틀 화면에서 진입)
- 타이틀에 "⭐ 영구 강화" 버튼 → `state = "meta"` 오버레이.
- 5개 항목 (이름 / 효과 / 최대 레벨 / 비용 공식):
  1. 시작 골드: 시작 골드 +50/Lv, 최대 10, 비용 `floor(20 * 1.5^lv)`
  2. 시작 등급: 시작 무기 2개의 등급 +1/Lv, 최대 5, 비용 `floor(100 * 3^lv)`
  3. 생명: 시작 생명 +1/Lv, 최대 5, 비용 `floor(50 * 2^lv)`
  4. 스킬 단련: 스킬 쿨다운 -5%/Lv, 최대 8, 비용 `floor(40 * 2^lv)`
  5. 행운: 뽑기 6등급+ 구간 가중치 +8%/Lv, 최대 10, 비용 `floor(60 * 2^lv)`
- 각 행: 이름, 현재 레벨/최대, 비용 버튼(보유 부족 시 회색, MAX 시 "MAX").
- 뒤로 버튼 → 타이틀 복귀. 보유 별조각 상단 표시.

### 적용 지점
- `reset()`: `gold = 150 + meta.gold*50`, `lives = 10 + meta.lives`, 시작 유닛 2개 tier `1 + meta.tier`.
- 스킬 사용 시 쿨다운: `skills[k] = max * (1 - meta.cdr*0.05)`.
- `rollBuyTier()`: weights[5..9]에 `* (1 + meta.luck*0.08)` 곱.

## 1-2. 웨이브 버프 카드 (5웨이브마다 3택1)

- 웨이브 클리어 시 `wave % 5 === 0`이면 다음 웨이브 시작 전에 `state = "card"` (게임 일시정지 — update의 전투 로직 정지).
- 카드 풀에서 중복 없이 3장 랜덤 제시. 이미 보유한 "1회성" 카드는 풀에서 제외.
- 런 한정 버프 배열 `runBuffs`(id 목록)에 저장, 관련 로직에서 참조.
- 카드 풀 (id / 이름 / 효과):
  - `pierce40`: 관통의 극의 — pierce/wave류 데미지 +40% (중첩 가능)
  - `aoe25`: 폭심지 — 모든 aoe 반경 +25% (1회성)
  - `burn2`: 겁화 — 화상 지속시간 2배 (1회성)
  - `chain2`: 전도체 — 체인 연쇄 +2 (1회성)
  - `gold30`: 황금손 — 처치 골드 +30% (중첩 가능)
  - `spawn20`: 조달 계약 — 무기 자동 생성 속도 +20% (중첩 가능)
  - `sell2`: 고물상 — 판매가 2배 (1회성)
  - `freeze2`: 절대영도 — 프리즈 지속 +2초 (1회성)
  - `meteor2`: 유성우 — 메테오 스킬 낙하 +2발 (1회성)
  - `jack2`: 대박 체질 — 합성 대박 확률 2배(24%) (1회성)
  - `atk10`: 광전사 — 모든 무기 공속 +10% (중첩 가능)
  - `dmg15`: 마력 각성 — 모든 무기 데미지 +15% (중첩 가능)
- 카드 UI: 화면 중앙 3장 세로 카드(제목+설명+아이콘), 탭하면 선택 연출 후 게임 재개.
- 효과 적용은 헬퍼 `buffCount(id)` (중첩 수 반환)로 각 지점에서 곱연산.

## 1-3. 무기 도감

- `localStorage 'smd_dex'`: 발견한 등급 배열. `addUnit`/합성/보스드랍에서 갱신.
- 타이틀 "📖 도감" 버튼 → `state = "dex"` 오버레이.
- 4열 x 5행 = 20칸. 발견: 등급 색 배경 + 이모지 + 이름. 미발견: 어두운 배경 + "?".
- 20종 모두 발견 시 상단에 "🏆 완전 정복!" 표시. 뒤로 버튼.

## 1-4. 결과 화면 강화

게임 오버 화면에 추가:
- 도달 웨이브 / 처치 수 / 최고 등급(이모지+이름) / 획득 별조각 "+N ⭐" / 신기록 여부
- 최종 무기 진형 미니 스냅샷 (5x3 축소판, 각 칸에 이모지)
- 두 버튼: "다시 시작" (즉시 새 게임), "타이틀로".

## 공통 요구사항

- `state` 값: 기존 `title|play|over`에 `meta|dex|card` 추가. 각 상태에서 그리기/입력 분기.
- 일시정지 상태(card)에서는 적/투사체/타이머 정지, 애니메이션 time만 진행.
- 게임 오버 시 별조각 정산은 정확히 1회만 (중복 지급 금지 — 플래그 사용).
- 모든 버튼 터치/마우스 지원 (기존 onDown 패턴).
- JS 오류 0건. 기존 기능(합성/판매/스킬/자동생성) 무결성 유지.

## 검증 기준 (리뷰어 체크리스트)

1. 게임 오버 → 별조각 적립 → 타이틀 → 메타 상점 구매 → 새 게임에 효과 반영 흐름이 코드상 완결되는가
2. 카드 선택 중 게임이 완전히 멈추는가 / 선택 후 정확히 재개되는가
3. buffCount 적용 지점: 관통 dmg, aoe 반경, 화상, 체인 수, 처치 골드, 생성 속도, 판매가, 프리즈, 메테오, 대박 확률, 공속, 데미지 — 전부 실제로 참조되는가
4. localStorage 파싱 실패(빈 값/구버전) 시 안전한 기본값 폴백
5. 중복 지급/이중 정산/상태 전이 누락 버그 없는가
